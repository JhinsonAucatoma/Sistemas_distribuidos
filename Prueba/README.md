Pasos para ejecutar
- Primeramente ubicarse en https://github.com/JhinsonAucatoma/Sistemas_distribuidos/tree/main/Prueba/demo1/src/main/java/ec/edu/uteq/distribuidas/socket,
ya que ahí se encontrarán los archivos a ejecutar.
- Abrir el proyecto en IntelliJ IDEA.
- Ejecutar primero ServidorTCP.java. Este levanta el servidor en el puerto 9000 y queda esperando conexiones.
- En terminales separadas, ejecutar ClienteTCP.java, Nodo2.java y Nodo3.java para conectar los tres nodos.
